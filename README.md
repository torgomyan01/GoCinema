## Շաբաթական հաշվետվություն

Ադմինը երկուշաբթի կայք մտնելիս ավտոմատ ուղարկում է նախորդ շաբաթվա հաշվետվությունները արտադրողի email-ին։

Resend-ում պետք է հաստատված դոմեն լինի։ Հիմա API key-ի վրա հաստատված է `tend.am`, դրա համար `.env`-ում `RESEND_FROM=GoCinema <noreply@tend.am>`։ `gocinema.am`-ը հաստատելուց հետո կարող ես փոխել `info@gocinema.am`։
